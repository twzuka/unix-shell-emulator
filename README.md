# Эмулятор командной оболочки UNIX

Консольный эмулятор оболочки UNIX-подобной системы на Python. Поддерживает интерактивный режим и выполнение сценариев, работает с виртуальной файловой системой, загружаемой из XML.

## Возможности

- Интерактивный REPL с настраиваемым приглашением
- Выполнение стартового сценария из текстового файла
- Виртуальная файловая система (VFS), описанная в XML, с поддержкой бинарных файлов через base64
- Команды: `ls`, `cd`, `cat`, `head`, `touch`, `chown`, `uptime`, `exit`
- Изменения в VFS живут в текущем сеансе и не сохраняются на диск

## Требования

- Python 3.9 или новее
- Windows или Linux

Используется только стандартная библиотека Python, установка зависимостей не требуется.

## Быстрый запуск

Все команды выполняются из корня репозитория.

**Windows**

```powershell
python src/main.py --vfs-path vfs/minimal.xml
```

или

```powershell
.\run.bat --vfs-path vfs/minimal.xml
```

**Linux**

```bash
python3 src/main.py --vfs-path vfs/minimal.xml
```

или

```bash
./run.sh --vfs-path vfs/minimal.xml
```

Для завершения работы введите `exit`.

## Параметры запуска

| Параметр | Назначение | Значение по умолчанию |
|---|---|---|
| `--vfs-path PATH` | Путь к XML-файлу виртуальной файловой системы | Обязательный |
| `--prompt TEXT` | Текст приглашения к вводу | Формируется из имени пользователя и хоста |
| `--script PATH` | Путь к стартовому сценарию | Не задан |

Пример с полным набором параметров:

```bash
python3 src/main.py --vfs-path vfs/minimal.xml --prompt "demo> " --script scripts/startup.txt
```

Значения с пробелами заключайте в кавычки. Справка: `python src/main.py --help`.

## Команды

| Команда | Описание |
|---|---|
| `ls [-a] [-l] [PATH ...]` | Список элементов; `-a` показывает скрытые, `-l` — тип, владельца, группу, размер и время изменения |
| `cd [PATH]` | Смена каталога; без аргумента переход в `/`, `cd -` возвращает в предыдущий каталог |
| `uptime` | Время работы эмулятора с момента запуска |
| `cat FILE ...` | Вывод содержимого UTF-8 файлов |
| `head [-n N \| --lines=N] FILE ...` | Первые N строк файла (по умолчанию 10) |
| `chown OWNER[:GROUP] PATH ...` | Смена владельца и группы эмулируемого объекта |
| `touch [-a] [-m] [-c] PATH ...` | Создание пустых файлов и обновление временных меток |
| `exit` | Завершение работы |

Пути могут быть абсолютными (`/documents`) или относительными (`study/practice`). Поддерживаются `.`, `..` и повторные `/`. Для имён, начинающихся с дефиса, используйте `--`, например `cat -- -file.txt`.

Ошибки неизвестных команд, аргументов и путей выводятся в консоль, и сеанс продолжается.

## Пример сеанса

```text
demo> cd /documents/study/practice
demo> cat task.txt
Вариант 13
demo> cd /
demo> head -n 2 lines.txt
Строка 1
Строка 2
demo> cat missing
cat: missing: no such file or directory
demo> exit
```

## Формат VFS

Виртуальная файловая система описывается XML-файлом:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<vfs>
    <directory name="documents">
        <file name="notes.txt" encoding="text">Первая строка
Вторая строка</file>
    </directory>
    <file name="data.bin" encoding="base64">AAEC/w==</file>
</vfs>
```

- `<vfs>` — корневой каталог `/`
- `<directory name="...">` — каталог, может содержать файлы и другие каталоги
- `<file name="..." encoding="text|base64">` — файл; если `encoding` не указан, используется `text`
- Имена внутри одного каталога должны быть уникальны; имена `.`, `..` и с разделителями `/` или `\` не допускаются

Исходный XML-файл не изменяется.

## Стартовый сценарий

Текстовый файл в кодировке UTF-8, в каждой строке одна команда:

```text
ls
ls -l
cd /documents/study/practice
cat task.txt
unknown_command
exit
```

Ошибки в сценарии не останавливают выполнение. Если сценарий завершился без `exit`, запускается интерактивный режим.

## Структура проекта

```text
src/
├── main.py       # CLI, сценарии, REPL, обработка ошибок
├── vfs.py        # Объекты VFS, загрузка XML и base64
├── session.py    # Состояние оболочки и виртуальные пути
├── options.py    # Разбор опций команд
├── commands.py   # Команды просмотра и навигации
└── mutations.py  # Команды изменения (touch, chown)
tests/            # Автотесты
vfs/              # Примеры VFS
scripts/          # Стартовые сценарии и скрипты проверки
run.sh, run.bat   # Запуск с передачей параметров
```

## Ограничения

- Нет пайпов, перенаправления ввода-вывода и подстановки переменных окружения
- `cat` и `head` работают только с файлами, чтение из stdin не поддерживается
- Изменения в VFS не сохраняются между запусками
